# 05 — persistence-layer

## Goal

Stand up the persistence backbone: Neon Postgres schema (4 tables
with RLS), the repository pattern that enforces ownership at the
application layer, the `BlobStore` interface with a Cloudflare R2
implementation for snapshot storage, and the Clerk webhook handler
that syncs `user.created` / `user.updated` / `user.deleted` events
into the `users` table. After this spec, missions, tasks, saved
selectors, and HTML snapshots all have durable, type-safe,
ownership-checked storage; cross-tenant queries fail at the
database layer (RLS) even when the application layer has a bug.

## Dependencies

- `specs/01-monorepo-skeleton.md` — workspaces, Turbo tasks
- `specs/02-linting-and-formatting.md` — strict mypy is required
  for the typed repository
- `specs/04-clerk-auth-and-security-foundation.md` — `CurrentUser`
  context and `require_user` dependency are reused; the webhook
  endpoint reuses the auth-free side of `app/main.py`

## Design Decisions

- **Stack**: `sqlmodel` + `asyncpg` + `alembic`. sqlmodel gives
  Pydantic v2-validated ORM models in one declaration; asyncpg is
  the fastest async Postgres driver; alembic owns migrations.
- **Database**: **Neon Postgres** free tier (3 GB). Local dev
  uses Neon dev branches so schema, RLS, and pooler behavior match
  prod exactly.
- **Migrations**: alembic, autogenerated then hand-edited for RLS
  policies (alembic does not autogenerate `CREATE POLICY` /
  `ALTER TABLE ... ENABLE ROW LEVEL SECURITY`).
- **RLS strategy**: every transaction begins with
  `SET LOCAL app.user_id = '<uuid>'`. Policies match on
  `current_setting('app.user_id', true)`. The repository layer is
  the only place that issues `SET LOCAL`; routes and business
  logic never touch it directly.
- **`users` table has no RLS** — Clerk owns identity; the table
  exists to satisfy foreign keys from `missions.user_id`. The
  webhook is the only writer.
- **`saved_selectors` has no RLS** — selectors are deployment-
  scoped per the architecture decision (cross-user reuse for cache
  efficiency; no PII). Open question 5 in `progress-tracker.md`
  tracks revisiting this if a B2B customer needs isolation.
- **Blob store**: `BlobStore` ABC with two implementations —
  `R2BlobStore` (production) and `LocalFsBlobStore` (tests, dev).
  Selected at startup via `BLOB_STORE_BACKEND=r2|local`. Path
  template: `{user_id}/{mission_id}/{task_id}.html.gz`. Max 10 MB
  per object; oversize bodies truncate and the row is flagged.
- **Webhook signature verification**: `svix` Python SDK. Clerk
  signs every webhook with Svix; the SDK handles the timestamp
  and signature checks in one call.
- **Connection pooling**: Neon's PgBouncer-style pooler in
  transaction mode. The connection string for app code uses
  `?sslmode=require&pgbouncer=true`. Migrations connect to the
  unpooled URL because alembic uses session-level features.
- **Status enum** values: `pending | running | succeeded |
  failed | cancelled`. Defined as a Postgres enum for query
  performance and as a Python `str` enum for type safety.
- **UUIDv4 for `missions.id`, `tasks.id`, `saved_selectors.id`**.
  `users.id` is the **Clerk user_id string**, not a UUID — Clerk
  owns identity.
- **No public-write columns**. Every column is set by the
  repository or by Clerk webhooks. Routes never write directly.
- **`apps/api/app/persistence/` is owned by this spec.** No
  invariant requires it to be protected from later specs (unlike
  `security.py`), but every later spec routes through the
  repository — never raw SQL.

### B. sqlmodel models (`apps/api/app/persistence/models.py`)

```python
from __future__ import annotations

import uuid
from datetime import datetime
from enum import StrEnum

from sqlalchemy import Index, text
from sqlmodel import Column, Field, Relationship, SQLModel
from sqlalchemy.dialects.postgresql import JSONB


class MissionMode(StrEnum):
    URL = "url"
    DESCRIPTION = "description"


class Status(StrEnum):
    PENDING = "pending"
    RUNNING = "running"
    SUCCEEDED = "succeeded"
    FAILED = "failed"
    CANCELLED = "cancelled"


class Tier(StrEnum):
    HTTP = "http"
    STEALTH = "stealth"
    DYNAMIC = "dynamic"


class User(SQLModel, table=True):
    __tablename__ = "users"

    id: str = Field(primary_key=True, max_length=64)  # Clerk user_id
    email: str = Field(max_length=320, index=True)
    created_at: datetime = Field(
        sa_column_kwargs={"server_default": text("now()")},
    )

    missions: list["Mission"] = Relationship(back_populates="user")


class Mission(SQLModel, table=True):
    __tablename__ = "missions"

    id: uuid.UUID = Field(default_factory=uuid.uuid4, primary_key=True)
    user_id: str = Field(foreign_key="users.id", index=True, max_length=64)
    prompt: str = Field(max_length=2000)
    mode: MissionMode
    status: Status = Field(default=Status.PENDING)
    cost_cents: int = Field(default=0)
    robots_override: bool = Field(default=False)
    created_at: datetime = Field(
        sa_column_kwargs={"server_default": text("now()")},
    )
    finished_at: datetime | None = None

    user: User = Relationship(back_populates="missions")
    tasks: list["Task"] = Relationship(back_populates="mission")

    __table_args__ = (
        Index("ix_missions_user_id_status", "user_id", "status"),
    )


class Task(SQLModel, table=True):
    __tablename__ = "tasks"

    id: uuid.UUID = Field(default_factory=uuid.uuid4, primary_key=True)
    mission_id: uuid.UUID = Field(foreign_key="missions.id", index=True)
    url: str = Field(max_length=2048)
    tier_used: Tier
    status: Status = Field(default=Status.PENDING)
    latency_ms: int | None = None
    parsed_markdown: str | None = Field(default=None)
    snapshot_key: str | None = Field(default=None, max_length=512)
    snapshot_truncated: bool = Field(default=False)
    selector_cache_id: uuid.UUID | None = Field(
        default=None, foreign_key="saved_selectors.id"
    )
    started_at: datetime | None = None
    finished_at: datetime | None = None

    mission: Mission = Relationship(back_populates="tasks")


class SavedSelector(SQLModel, table=True):
    __tablename__ = "saved_selectors"

    id: uuid.UUID = Field(default_factory=uuid.uuid4, primary_key=True)
    domain: str = Field(max_length=253, index=True)
    purpose: str = Field(max_length=64, index=True)
    payload: dict = Field(sa_column=Column(JSONB, nullable=False))
    hit_count: int = Field(default=0)
    last_used_at: datetime = Field(
        sa_column_kwargs={"server_default": text("now()")},
    )

    __table_args__ = (
        Index(
            "ix_saved_selectors_domain_purpose",
            "domain",
            "purpose",
            unique=True,
        ),
    )
```

The covering index on `(domain, purpose)` is unique because
`SavedSelector` is keyed on that pair (architecture invariant 8);
duplicates would corrupt the LRU cache.

### C. Database session + RLS-aware engine (`apps/api/app/persistence/db.py`)

```python
from __future__ import annotations

from collections.abc import AsyncIterator
from contextlib import asynccontextmanager

from sqlalchemy.ext.asyncio import (
    AsyncSession,
    async_sessionmaker,
    create_async_engine,
)
from sqlalchemy import text

from app.config import settings
from app.security import _current_user  # internal — repository only


_engine = create_async_engine(settings.database_url, pool_pre_ping=True)
_session_factory = async_sessionmaker(_engine, expire_on_commit=False, class_=AsyncSession)


@asynccontextmanager
async def transaction() -> AsyncIterator[AsyncSession]:
    """Open a transaction with `SET LOCAL app.user_id` bound."""
    user = _current_user.get()
    async with _session_factory() as session:
        async with session.begin():
            if user is not None:
                # SET LOCAL is scoped to this transaction only.
                # Critical when running on a transaction-pooled connection.
                await session.execute(
                    text("SET LOCAL app.user_id = :uid").bindparams(uid=user.user_id)
                )
            yield session
```

This is the **only** module allowed to read the `_current_user`
ContextVar from `security.py`. Repository methods enter
`async with transaction() as session:` and trust RLS to enforce
ownership.

### D. Repository layer (`apps/api/app/persistence/repository.py`)

```python
from __future__ import annotations

import uuid
from datetime import datetime, timezone

from sqlalchemy import select
from sqlmodel.ext.asyncio.session import AsyncSession

from app.persistence.db import transaction
from app.persistence.models import (
    Mission,
    MissionMode,
    SavedSelector,
    Status,
    Task,
    Tier,
    User,
)


class MissionRepository:
    async def create(
        self,
        *,
        user_id: str,
        prompt: str,
        mode: MissionMode,
        robots_override: bool = False,
    ) -> Mission:
        async with transaction() as session:
            mission = Mission(
                user_id=user_id,
                prompt=prompt,
                mode=mode,
                robots_override=robots_override,
            )
            session.add(mission)
            await session.flush()
            return mission

    async def get(self, mission_id: uuid.UUID) -> Mission | None:
        async with transaction() as session:
            return await session.get(Mission, mission_id)

    async def list_by_status(self, status: Status) -> list[Mission]:
        async with transaction() as session:
            stmt = select(Mission).where(Mission.status == status)
            result = await session.execute(stmt)
            return list(result.scalars().all())

    async def update_status(self, mission_id: uuid.UUID, status: Status) -> None:
        async with transaction() as session:
            mission = await session.get(Mission, mission_id)
            if mission is None:
                return  # RLS hid the row or it doesn't exist
            mission.status = status
            if status in {Status.SUCCEEDED, Status.FAILED, Status.CANCELLED}:
                mission.finished_at = datetime.now(timezone.utc)


class TaskRepository:
    async def create(
        self,
        *,
        mission_id: uuid.UUID,
        url: str,
        tier_used: Tier,
    ) -> Task:
        async with transaction() as session:
            task = Task(mission_id=mission_id, url=url, tier_used=tier_used)
            session.add(task)
            await session.flush()
            return task

    async def update(
        self,
        task_id: uuid.UUID,
        *,
        status: Status | None = None,
        latency_ms: int | None = None,
        parsed_markdown: str | None = None,
        snapshot_key: str | None = None,
        snapshot_truncated: bool | None = None,
        selector_cache_id: uuid.UUID | None = None,
    ) -> None:
        async with transaction() as session:
            task = await session.get(Task, task_id)
            if task is None:
                return
            if status is not None:
                task.status = status
                if status == Status.RUNNING and task.started_at is None:
                    task.started_at = datetime.now(timezone.utc)
                if status in {Status.SUCCEEDED, Status.FAILED, Status.CANCELLED}:
                    task.finished_at = datetime.now(timezone.utc)
            if latency_ms is not None:
                task.latency_ms = latency_ms
            if parsed_markdown is not None:
                task.parsed_markdown = parsed_markdown
            if snapshot_key is not None:
                task.snapshot_key = snapshot_key
            if snapshot_truncated is not None:
                task.snapshot_truncated = snapshot_truncated
            if selector_cache_id is not None:
                task.selector_cache_id = selector_cache_id


class SelectorRepository:
    async def get(self, domain: str, purpose: str) -> SavedSelector | None:
        async with transaction() as session:
            stmt = select(SavedSelector).where(
                SavedSelector.domain == domain,
                SavedSelector.purpose == purpose,
            )
            result = await session.execute(stmt)
            return result.scalars().first()

    async def upsert(
        self, *, domain: str, purpose: str, payload: dict
    ) -> SavedSelector:
        async with transaction() as session:
            existing = await self.get(domain, purpose)
            if existing is None:
                selector = SavedSelector(domain=domain, purpose=purpose, payload=payload)
                session.add(selector)
                await session.flush()
                return selector
            existing.payload = payload
            existing.hit_count += 1
            existing.last_used_at = datetime.now(timezone.utc)
            return existing


class UserRepository:
    """Webhook-only writer. No RLS (users table is identity, not data)."""

    async def upsert(self, *, user_id: str, email: str) -> User:
        async with transaction() as session:
            user = await session.get(User, user_id)
            if user is None:
                user = User(id=user_id, email=email)
                session.add(user)
            else:
                user.email = email
            await session.flush()
            return user

    async def delete(self, user_id: str) -> None:
        async with transaction() as session:
            user = await session.get(User, user_id)
            if user is not None:
                await session.delete(user)
```

The repository never re-implements ownership checks — RLS does it.
The application-layer redundancy (re-asserting `WHERE user_id =
:uid` in queries) is unnecessary because `SET LOCAL app.user_id`
combined with RLS makes the database refuse to return foreign rows.

### E. Blob store (`apps/api/app/persistence/blob.py`)

```python
from __future__ import annotations

import gzip
from abc import ABC, abstractmethod
from pathlib import Path
from typing import Final
from uuid import UUID

import boto3
from botocore.config import Config

from app.config import settings


MAX_SNAPSHOT_BYTES: Final = 10 * 1024 * 1024  # 10 MB


class BlobStore(ABC):
    @abstractmethod
    async def put(
        self, *, user_id: str, mission_id: UUID, task_id: UUID, body: bytes
    ) -> tuple[str, bool]:
        """Returns (key, truncated). Body is gzipped before write."""

    @abstractmethod
    async def get(self, key: str) -> bytes:
        """Returns gunzipped body."""

    @abstractmethod
    async def signed_url(self, key: str, *, expires_in_seconds: int = 3600) -> str:
        ...


def _key(user_id: str, mission_id: UUID, task_id: UUID) -> str:
    return f"{user_id}/{mission_id}/{task_id}.html.gz"


def _gzip_truncate(body: bytes) -> tuple[bytes, bool]:
    truncated = len(body) > MAX_SNAPSHOT_BYTES
    if truncated:
        body = body[:MAX_SNAPSHOT_BYTES]
    return gzip.compress(body), truncated


class R2BlobStore(BlobStore):
    def __init__(self) -> None:
        self._client = boto3.client(
            "s3",
            endpoint_url=f"https://{settings.r2_account_id}.r2.cloudflarestorage.com",
            aws_access_key_id=settings.r2_access_key_id,
            aws_secret_access_key=settings.r2_secret_access_key,
            config=Config(signature_version="s3v4"),
            region_name="auto",
        )

    async def put(
        self, *, user_id: str, mission_id: UUID, task_id: UUID, body: bytes
    ) -> tuple[str, bool]:
        key = _key(user_id, mission_id, task_id)
        gz, truncated = _gzip_truncate(body)
        # boto3 is sync; for MVP we accept the blocking call.
        # Spec 15 (hardening) revisits with aioboto3 if profiling demands it.
        self._client.put_object(
            Bucket=settings.r2_bucket,
            Key=key,
            Body=gz,
            ContentType="text/html",
            ContentEncoding="gzip",
        )
        return key, truncated

    async def get(self, key: str) -> bytes:
        obj = self._client.get_object(Bucket=settings.r2_bucket, Key=key)
        return gzip.decompress(obj["Body"].read())

    async def signed_url(self, key: str, *, expires_in_seconds: int = 3600) -> str:
        return self._client.generate_presigned_url(
            "get_object",
            Params={"Bucket": settings.r2_bucket, "Key": key},
            ExpiresIn=expires_in_seconds,
        )


class LocalFsBlobStore(BlobStore):
    """Dev / test backend. Writes under apps/api/data/snapshots/."""

    def __init__(self, root: Path | None = None) -> None:
        self._root = root or Path("data/snapshots")
        self._root.mkdir(parents=True, exist_ok=True)

    async def put(
        self, *, user_id: str, mission_id: UUID, task_id: UUID, body: bytes
    ) -> tuple[str, bool]:
        key = _key(user_id, mission_id, task_id)
        path = self._root / key
        path.parent.mkdir(parents=True, exist_ok=True)
        gz, truncated = _gzip_truncate(body)
        path.write_bytes(gz)
        return key, truncated

    async def get(self, key: str) -> bytes:
        return gzip.decompress((self._root / key).read_bytes())

    async def signed_url(self, key: str, *, expires_in_seconds: int = 3600) -> str:
        # Dev-only: return a `file://` URL. Not actually signed; not used in prod.
        return f"file://{(self._root / key).resolve()}"


def get_blob_store() -> BlobStore:
    if settings.blob_store_backend == "r2":
        return R2BlobStore()
    return LocalFsBlobStore()
```

Use `get_blob_store` as a FastAPI dependency where blob writes are
needed (Spec 07 onward).

from __future__ import annotations

import asyncio
from logging.config import fileConfig

from alembic import context
from sqlalchemy import pool
from sqlalchemy.engine import Connection
from sqlalchemy.ext.asyncio import create_async_engine
from sqlmodel import SQLModel

from app.config import settings
from app.persistence import models  # noqa: F401  ensures models register


config = context.config
if config.config_file_name is not None:
    fileConfig(config.config_file_name)

target_metadata = SQLModel.metadata


def run_migrations_offline() -> None:
    context.configure(
        url=settings.database_url_unpooled,
        target_metadata=target_metadata,
        literal_binds=True,
        dialect_opts={"paramstyle": "named"},
    )
    with context.begin_transaction():
        context.run_migrations()


def do_run_migrations(connection: Connection) -> None:
    context.configure(connection=connection, target_metadata=target_metadata)
    with context.begin_transaction():
        context.run_migrations()


async def run_migrations_online() -> None:
    engine = create_async_engine(
        settings.database_url_unpooled, poolclass=pool.NullPool
    )
    async with engine.connect() as connection:
        await connection.run_sync(do_run_migrations)
    await engine.dispose()


if context.is_offline_mode():
    run_migrations_offline()
else:
    asyncio.run(run_migrations_online())
```

def upgrade() -> None:
    # ... autogenerated table creates ...

    # RLS on missions
    op.execute("ALTER TABLE missions ENABLE ROW LEVEL SECURITY")
    op.execute("ALTER TABLE missions FORCE ROW LEVEL SECURITY")
    op.execute(
        "CREATE POLICY missions_owner ON missions "
        "USING (user_id = current_setting('app.user_id', true)) "
        "WITH CHECK (user_id = current_setting('app.user_id', true))"
    )

    # RLS on tasks (scoped via mission)
    op.execute("ALTER TABLE tasks ENABLE ROW LEVEL SECURITY")
    op.execute("ALTER TABLE tasks FORCE ROW LEVEL SECURITY")
    op.execute(
        "CREATE POLICY tasks_owner ON tasks "
        "USING (EXISTS ("
        "  SELECT 1 FROM missions m "
        "  WHERE m.id = tasks.mission_id "
        "    AND m.user_id = current_setting('app.user_id', true)"
        ")) "
        "WITH CHECK (EXISTS ("
        "  SELECT 1 FROM missions m "
        "  WHERE m.id = tasks.mission_id "
        "    AND m.user_id = current_setting('app.user_id', true)"
        "))"
    )


def downgrade() -> None:
    op.execute("DROP POLICY IF EXISTS tasks_owner ON tasks")
    op.execute("ALTER TABLE tasks DISABLE ROW LEVEL SECURITY")
    op.execute("DROP POLICY IF EXISTS missions_owner ON missions")
    op.execute("ALTER TABLE missions DISABLE ROW LEVEL SECURITY")

    # ... autogenerated table drops ...
```

`FORCE ROW LEVEL SECURITY` ensures policies apply even to table
owners — critical because Neon's connection user often is the table
owner.

### G. Clerk webhook (`apps/api/app/routes.py`)

```python
from __future__ import annotations

from fastapi import APIRouter, HTTPException, Request, status
from svix.webhooks import Webhook, WebhookVerificationError

from app.config import settings
from app.persistence.repository import UserRepository


router = APIRouter()
_users = UserRepository()


@router.post("/webhooks/clerk", status_code=status.HTTP_204_NO_CONTENT)
async def clerk_webhook(request: Request) -> None:
    body = await request.body()
    headers = {
        "svix-id": request.headers.get("svix-id", ""),
        "svix-timestamp": request.headers.get("svix-timestamp", ""),
        "svix-signature": request.headers.get("svix-signature", ""),
    }
    try:
        wh = Webhook(settings.clerk_webhook_signing_secret)
        event = wh.verify(body, headers)
    except WebhookVerificationError:
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "invalid signature")

    event_type = event.get("type")
    data = event.get("data", {})

    if event_type == "user.created" or event_type == "user.updated":
        user_id = data["id"]
        # Pick primary email; Clerk's payload has email_addresses[].
        emails = data.get("email_addresses", [])
        primary_id = data.get("primary_email_address_id")
        primary = next(
            (e for e in emails if e.get("id") == primary_id),
            emails[0] if emails else None,
        )
        if primary is None:
            raise HTTPException(
                status.HTTP_400_BAD_REQUEST, "no email on user"
            )
        await _users.upsert(user_id=user_id, email=primary["email_address"])

    elif event_type == "user.deleted":
        user_id = data.get("id")
        if user_id is None:
            raise HTTPException(
                status.HTTP_400_BAD_REQUEST, "missing user id on deletion"
            )
        await _users.delete(user_id=user_id)

    # other event types are silently 204'd — Clerk sends many we don't care about
```

## Scrape reliability note

This spec ships zero scraping behavior, but it ships the **durable
backbone** every scrape depends on. When Spec 07's first HTTP-tier
fetcher writes its first snapshot, that write goes through:

1. `assert_safe_url(url)` → security guard (Spec 04)
2. `assert_robots_allows(url, robots_override=mission.robots_override)` → robots check (Spec 04)
3. `task_repo.update(task_id, status=RUNNING)` → DB write inside `SET LOCAL app.user_id` transaction (Spec 05)
4. `blob_store.put(...)` → R2 with gzip + truncation cap (Spec 05)
5. `task_repo.update(task_id, status=SUCCEEDED, snapshot_key=key, parsed_markdown=...)` → DB write before any SSE event for the task fires (invariant 7, enforced by Spec 07's runner)

If any step fails, RLS, the unique index, or the FORCE policy
catches it before bad data lands. The reliability story is
defensive depth: invariants 1, 7, 8, 9, 10, 11 each have at least
one mechanical enforcer at this point in the build.
